# Greenmelons Guided Pitch: narration script

To use recorded voice, save each line as an MP3 in an `audio` folder using the file name shown. If a file is missing the site uses the browser voice for that line. Keep the wording and the file name in step with `tour.js`.

Whether you need creative support for your own marketing, or an extra pair of hands behind the scenes, we’re here to help you get the work done. So, let’s start with one question. Are you here as a business, or are you an agency?
